# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting instead:
open the **Security** tab of this repository and choose **Report a vulnerability**. Describe what you found, how to
reproduce it and which version or commit you used.

We will answer as soon as we can, work on a fix and tell you when it is released. This is a student project, so
there is no guaranteed response time.

## Supported versions

Only the latest release (and the current main branch) receives fixes.

## Credentials

If you find a password, token or key in this repository or its history, report it the same way. Do not use it.
